# CCNA 200-301 Adaptive Exam Simulator

An AI-driven interactive quiz simulator tailored for Cisco Certified Network Associate (CCNA 200-301) preparation. Built with Streamlit and powered by Google Gemini API.

## Features
- **Adaptive Question Weighting**: Automatically detects weak topics and adjusts question frequency.
- **Structured Explanations**: Detailed reasoning for correct answers and distractor analysis.
- **Multilingual Delivery**: Supports English, Swedish, Russian, Ukrainian, and Polish.
- **Session-Isolated State**: Zero token bloat and multi-user safety using native in-memory session management.
